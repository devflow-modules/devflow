# Terminologia comercial do portal

Guia de linguagem para o portal canónico. Não descreve comportamento de runtime.

## Produto

Preferir `WhatsApp Platform`.

Categoria: operação de conversas no WhatsApp.

## Inbox

Preferir `inbox compartilhado`.

## Responsável

Linguagem de compra: `responsável`.

No runtime, o conceito é o dono da conversa (`assignedToUserId`), com assumir, transferir e devolver.

## Fila

Linguagem de compra: `fila`.

A fila organiza o que precisa de resposta. Não implica roteamento por IA, habilidade, presença ou carga.

## Handoff

Preferir `handoff` ou transferência para uma pessoa, com o histórico.

## Automação

Preferir `automação supervisionada`.

Forma curta: automação no repetitivo; pessoa quando precisa.

Evitar recepcionista autônoma, IA 24/7 e bot inteligente.

## Implantação

Preferir `implantação acompanhada`.

Evitar self-service.

## Demonstrações

Separar prova de cliente real de dados ilustrativos e simulação.

A demo do portal é uma demonstração da plataforma, com dados ilustrativos.

## API

Preferir `WhatsApp Cloud API oficial da Meta`.

A implantação acompanhada não garante aprovação da conta.
